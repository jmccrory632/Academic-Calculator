Academic Companion

Academic Companion is a Java-based academic management application designed to help university students manage their coursework, monitor their academic progress, and stay organised throughout the academic year.

Built using object-oriented programming principles, the application provides tools for assignment tracking, module management, study session logging, grade calculation, degree classification prediction, and persistent file storage.

Features 

- Assignment Management
- Add assignments
- View assignments
- Delete assignments
- Mark assignments as completed
- Track assignment weightings and due dates
- Module Management
- Add modules
- View module information
- Record current grades
- Study Tracking
- Log study sessions
- Track total study hours
- Monitor study activity
- Academic Performance Tools
- Weighted grade calculator
- Degree classification predictor
- Academic dashboard displaying key statistics
- Data Persistence
- Automatically saves assignments to a text file
- Loads saved assignments when the application starts
- Prevents data loss between sessions
- Dashboard
- 
The application provides a dashboard displaying:
- Number of assignments
- Number of modules
- Total study hours logged
- 
This gives students a quick overview of their academic workload and progress.
