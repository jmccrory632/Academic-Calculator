Academic Companion
Academic Companion is a Java-based academic management application designed to help university students manage their studies.

Features include:
- Assignment Tracking
- Module Management
- Study Session Logging
- Grade Calculation
- Menu Driven Interface

Technologies Used:
- Java
- Object-Oriented Programming
- ArrayLists
- Scanner
- Future Improvements
- Save data to files
- SQLite database integration
- GPA prediction
- GUI using JavaFX

By Jack McCrory
